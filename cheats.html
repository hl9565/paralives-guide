Paralives Cheats: Early Access Cheat Console Commands

Updated: 2026-05-29 Game Version: EA 0.1 Cheat console

This Paralives cheats reference is a community-derived Early Access command list, rewritten for clarity and organized so you can quickly find economy, time, character, need, build, and debug commands.

Early Access warning: Cheats are developer-debug tools, not a stable player-facing API. Per a Paradev statement referenced on the paralives.wiki Cheats page, many of the roughly 300 commands may be removed, hidden, or reworked. The authoritative current list is whatever the in-game console shows. Last reviewed against paralives.wiki on 2026-05-29.

How to open the cheat console

Open the in-game console with Ctrl + F1 or Ctrl + Shift + C. If a command does not run, type HELP in the console and trust the list exposed by your current build.

Money cheats

CommandWhat it doesExample
PRINTMONEYAdds the entered amount of Paradimes to the current household.PRINTMONEY 1000
SETMONEYSets household funds to the exact amount you enter.SETMONEY 10000
JACKPOTGrants a large one-time money boost.
MAKEITRAINAdds a smaller large-payout money boost.
PAYDAYAdds a small household cash bump.
PIGGYBANKAdds a medium household cash bump.
LOTTERYTriggers a random money payout.

Time cheats

CommandWhat it doesExample
SETHOURMoves the clock to the specified hour.SETHOUR 8
ADVANCEHOURPushes the clock forward by one hour.
ADVANCEDAYSkips ahead to the next day.
SETSUNHOURSets the lighting to a specific sun hour.SETSUNHOUR 12
SKIPTO5MINUTESBEFOREWORKMoves time close to the selected character's work start.

Character cheats

CommandWhat it doesExample
EDITCHARACTEROpens character editing for the selected Para when available.
LEVELUPPERSONALITYAdvances a personality-related value for the selected character.
RESETPERSONALITYResets personality debug state for the selected character.
PRINTINVENTORYPrints the selected character's inventory debug output.
ADDITEMTOINVENTORYAdds an item to a selected character inventory when the item id is valid.ADDITEMTOINVENTORY item_id

Need cheats

CommandWhat it doesExample
RELIEFNEEDRefills a named need for the selected character.RELIEFNEED sleep
RELIEFALLNEEDSRefills all needs for the selected character.
RELIEFALLNEEDSOFALLCHARACTERSRefills needs for every character.
CHANGENEEDChanges a need by id and intensity if the build exposes that syntax.CHANGENEED sleep 20
DECAYNEEDForces a need to drop by a specified amount.DECAYNEED hunger 20

Occupation cheats
