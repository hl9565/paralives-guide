Color Palette Planner

Updated: 2026-06-05 Game Version: EA 0.1 Tools

Build a small color palette before you paint it on the color wheel in-game. Pick a base color, generate a harmony, rename swatches, copy values, and export the result from this browser.

This is a generic palette planner. It does not claim any specific in-game color-code fields, saved-palette limits, pattern controls, or numeric customization caps.

Base and harmony

Harmony math is standard HSL color theory; every swatch remains editable as a label only.

Export

The planner auto-saves locally on this device.
