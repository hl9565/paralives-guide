Tools

The tools layer is reserved for small helpers that solve a real player problem quickly. Every tool on this site will stay lightweight, browser-only, and usable without accounts, logins, or a backend service in the middle.

Status: PLANNED · Trait Conflict Checker first, with a Build Mode Size Calculator and Family Tree Planner behind it.

That sequence is deliberate: tools should follow verified game structure, not outrun it. Once the supporting data is solid enough, each tool ships as plain HTML, CSS, and vanilla JavaScript that works in one file.
