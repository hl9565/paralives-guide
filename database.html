Database

Updated: 2026-05-27 Game Version: EA 0.1 Database index

The database layer is where the site shifts from narrative to structured lookup. It will eventually hold quick-reference tables for traits, careers, furniture, and hobbies, but Phase 1 is keeping that discipline visible before it starts filling rows.

Status: PLANNED · The Paralives database opens with the Traits database. See the roadmap.

When this section opens, it will favor small verified datasets over noisy dumps. Five real verified rows beat fifty fabricated rows, especially in a game where dev-preview details can linger in fan memory long after the build changes.
